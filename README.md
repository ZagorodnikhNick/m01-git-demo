# M01 Git Demo

Демонстрационный проект к теме «Введение в веб-разработку. Git, GitHub и GitHub Pages».

Проект показывает базовый рабочий процесс:

- создание локального Git-репозитория;
- фиксацию изменений с помощью commit;
- работу с удалённым репозиторием GitHub;
- использование отдельной ветки;
- создание и слияние Pull Request;
- публикацию статического сайта с помощью GitHub Pages.

## Состав проекта

- `index.html` — демонстрационная HTML-страница;
- `styles.css` — стили страницы;
- `.gitignore` — исключения Git.

## Опубликованный сайт

Проект опубликован с помощью GitHub Pages:

## Как использовать проект

Можно изучить файлы проекта, историю коммитов, ветки и Pull Request, чтобы увидеть рассмотренный на занятии Git workflow на реальном примере.

Проект является демонстрационным примером. Практическое задание необходимо выполнять самостоятельно в собственном репозитории.
